# รัน SMS บน Vercel

ชุดนี้คือ SMS (School Management System) รุ่น 7.0.4 จาก https://github.com/goragodwiriya/sms
ดัดแปลงให้รันบน Vercel ได้ โดยแก้โค้ดของ SMS น้อยที่สุด

## สิ่งที่เพิ่มเข้ามา

| ไฟล์ | หน้าที่ |
|---|---|
| `vercel.json` | ใช้ PHP 8.3 (vercel-php) ทำงานที่สิงคโปร์ (`sin1`) และส่งทุกคำขอที่ต้องใช้ PHP ไปที่ `api/index.php` |
| `api/index.php` | จุดเข้าเดียวของเว็บ |
| `vercel/bootstrap.php` | ชั้นกลาง: คัดลอกโค้ดไป `/tmp` ให้เขียนไฟล์ได้, ซิงก์ `settings/` `datas/` `language/` กับฐานข้อมูล, เก็บ session ในฐานข้อมูล, แปลง URL แทน `.htaccess`, ปิดตัวติดตั้งหลังติดตั้งเสร็จ |
| `vercel/gd/` | ตัวแทนส่วนขยาย gd (Vercel ไม่มี gd) ใช้ย่อ/ครอปรูปผ่าน FFI ซอร์สอยู่ที่ `smsimg.c` คอมไพล์ด้วย `build.sh` |

แก้โค้ดของ SMS 3 จุด
- `load.php` ปิดแคชผลลัพธ์ query เมื่อรันบน Vercel (หลายเครื่องรันพร้อมกัน แคชจะไม่ตรงกัน)
- `Kotchasan/Connection/MySQLDriver.php` และ `install/db.php` เชื่อมต่อฐานข้อมูลแบบเข้ารหัส (TLS) ได้

## Environment Variables

| ชื่อ | ความหมาย |
|---|---|
| `DATABASE_URL` หรือ `TIDB_*` / `DB_*` | ค่าเชื่อมต่อ MySQL/TiDB (การเชื่อม TiDB ผ่าน Vercel Marketplace ใส่ให้อัตโนมัติ) |
| `DB_NAME` | ชื่อฐานข้อมูล (ค่าเริ่มต้น `sms`) |
| `DB_PREFIX` | คำนำหน้าตาราง (ค่าเริ่มต้น `app`) |
| `SMS_SETUP_KEY` | รหัสสำหรับเปิดตัวติดตั้ง `/install/?key=...` |
| `SMS_ALLOW_INSTALL` | ตั้งเป็น `1` ชั่วคราวเมื่อจะปรับรุ่น (เปิดตัวติดตั้งอีกครั้ง) |

## ติดตั้งครั้งแรก

1. เชื่อมฐานข้อมูล TiDB Cloud กับโปรเจกต์ (แท็บ Storage) แล้ว Redeploy
2. เปิด `https://<โดเมน>/install/?key=<SMS_SETUP_KEY>`
3. ทำตามขั้นตอน ตั้งบัญชีผู้ดูแลระบบ หน้าฐานข้อมูลกด “ติดตั้ง” ได้เลย (ใช้ค่าจาก Vercel อัตโนมัติ)

## ข้อจำกัด

- ไฟล์อัปโหลดได้ครั้งละไม่เกินประมาณ 4.5MB (ขีดจำกัดของ Vercel)
- ลายน้ำตัวอักษรบนรูป (watermark) ไม่ทำงาน รูปยังบันทึกได้ตามปกติ
- ไฟล์ที่อัปโหลดเก็บในฐานข้อมูล (ตาราง `vercel_files`) ถ้ามีไฟล์จำนวนมาก ควรดูพื้นที่ของแพ็กเกจฐานข้อมูล
